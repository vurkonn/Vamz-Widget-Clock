# Clock Widget Studio 1.3

Android homescreen clock widget with a customizable outline/solid digit renderer.

## Editor controls
- Live preview button
- Background: transparent, solid color, or photo from gallery
- 28 font-style choices from Android system families (Roboto variants, condensed, rounded, serif, monospace, casual, cursive, small caps) plus a separate font-weight selector
- 12/24-hour time, optional colon
- Date show/hide, date format, alignment, size, vertical position, and color
- Choose how many of the four digits use outline style (0–4)
- Outline thickness, solid stroke, digit size, horizontal stretch, spacing, and X/Y placement
- Frame show/hide, color, thickness, corner radius, and inset
- Separate HEX colors for outline, solid digits, date, frame, and background

## Build with GitHub Actions
1. Replace the project files in your repository on branch `main`.
2. Open **Actions** and wait for **Build Android APK** to finish.
3. Download the `ClockWidgetStudio-debug-apk` artifact from a successful run.
4. Install the APK, open the app, customize the clock, then add the widget to the home screen.

This project has not been compiled in this environment. Verify the GitHub Actions build before installing.
