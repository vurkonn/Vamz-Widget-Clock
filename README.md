# Clock Widget Studio

Android homescreen clock widget with editable outline + solid typography.

## Customization in the app
- Outline stroke thickness
- Solid digit thickness
- Digit size and spacing
- Rounded frame thickness and corner radius
- Show/hide date and frame
- Separate HEX colors for outline, solid digits, frame, and background
- Transparent, solid-color, or personal-photo background

## Build with GitHub Actions
1. Upload the complete project to your GitHub repository on branch `main`.
2. Open **Actions** and run **Build Android APK** (or let the push trigger it).
3. Download the `ClockWidgetStudio-debug-apk` artifact from the successful run.
4. Install the APK, open the app, customize the clock, then add the Clock Widget Studio widget to the home screen.

The workflow builds a debug APK for testing.
